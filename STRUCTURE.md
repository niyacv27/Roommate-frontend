# RoomMate Radar Frontend Structure

This frontend is organized in the same role-based style as the Book Store reference project.

- API/: Axios configuration and API helpers
- Services/: application API service functions
- ContextAPI/: authentication and application state contexts
- assets/Admin/Pages/: admin pages
- assets/Lister/Pages/: room-lister pages
- assets/User/Pages/: normal-user/public pages
- assets/Components/: shared reusable components
